# A one-minute conservatory walkthrough

Pitch: **Every game of chess leaves a different garden.**

Use the deployed app. For the hackathon recording, first make the deployment publicly reachable and finish the TestSprite GitHub App check described in the README. The current private preview is for the owner’s review.

| Time | Show | Say |
| --- | --- | --- |
| 0–8 s | The complete conservatory in morning light. | “This is The Queen’s Conservatory: a chess game inside a little living glasshouse.” |
| 8–18 s | A White move, the keeper’s reply, and the move journal. | “It plays standard chess, with a local computer opponent, full legal moves, and a game you can return to.” |
| 18–33 s | Garden studies → The first bloom → d5. Let the capture animation finish. | “A capture doesn’t disappear. It becomes a seed, travels into the soil, and grows into a flower.” |
| 33–42 s | Undo, then repeat the capture. Switch to evening light. | “Undo restores the board and its garden. Every match grows its own record.” |
| 42–52 s | Garden studies → Room to become → a8 → queen. | “Promotion and the other special moves work too. The studies make them easy to explore.” |
| 52–60 s | The actual TestSprite run evidence and, once configured, the actual GitHub PR check. | Describe only what the displayed run and check really verified. Do not claim a green GitHub check before it exists. |

Optional extended moment: open **One final move**, click g7, and show the checkmate result card. Close with the final garden and the live public URL.

Record a real run rather than simulating a failure, result, or PR check. If demonstrating a defect caught and fixed, retain its original failing assertion and the successful rerun.
